# Java 工程实验路线

## 目标
以 Java 后端工程岗位为目标，通过可复现实验建立原理理解、设计、排障和优化能力。完成实验不等同于生产经验，不以背诵或实验数量直接认定精通。

## 技术基线
JDK 17 基线，更新版本特性单独验证。遵循仓库 Maven 结构，具体版本在实现阶段固定。

## 能力清单

| 模块 | 核心知识 | 验证实验 |
|---|---|---|
| 语言与类型系统 | 泛型擦除、反射、注解、异常 | Lab 01：泛型桥接与反射框架 |
| 集合与对象契约 | List、Map、Set、equals/hashCode、Comparator | Lab 02：集合选型与哈希冲突 |
| 并发与内存模型 | JMM、volatile、synchronized、CAS、Lock | Lab 03：共享库存并发正确性 |
| 线程池与异步编排 | Executor、Future、CompletableFuture、拒绝策略 | Lab 04：聚合接口过载与超时 |
| I/O 与网络 | BIO/NIO、Selector、缓冲区、编码 | Lab 05：高并发 TCP 服务 |
| 函数式与数据处理 | Stream、Collectors、Optional、并行流 | Lab 06：批量订单统计 |
| 工程质量与性能 | JUnit、JMH、异常边界、资源管理 | Lab 07：定位 Java 应用性能退化 |
| 扩展机制与模块化 | SPI、ServiceLoader、JPMS、类加载边界 | Lab 08：可插拔支付策略框架 |

## 交付规范
每个实验包含问题背景、假设、架构或时序图、可运行代码、固定版本环境、自动化测试或故障脚本、实际日志、对照结果、局限与清理命令。压测和故障注入仅在隔离环境进行。按 `java/lab-XX-*/` 组织，完成后更新状态及成果链接；一个实验一个 PR。

## 简历表达
完成相应实验后据实描述：熟练掌握 Java 的核心机制，能够复现和分析典型工程问题，设计解决方案并通过测试或压测验证。没有真实生产经验时不声称生产调优或故障处理经历。
