# MySQL 工程实验路线

## 目标
以 Java 后端工程岗位为目标，通过可复现实验建立原理理解、设计、排障和优化能力。完成实验不等同于生产经验，不以背诵或实验数量直接认定精通。

## 技术基线
MySQL 8.x，固定具体版本与 InnoDB 配置。遵循仓库 Maven 结构，具体版本在实现阶段固定。

## 能力清单

| 模块 | 核心知识 | 验证实验 |
|---|---|---|
| 数据建模与 SQL | 数据类型、约束、范式、JOIN、窗口函数 | Lab 01：订单数据库建模与复杂查询 |
| 索引与执行计划 | B+Tree、联合索引、覆盖索引、回表 | Lab 02：慢 SQL 索引优化 |
| 事务与隔离 | ACID、MVCC、Read View、隔离级别 | Lab 03：并发事务异常复现 |
| 锁与死锁 | 记录锁、间隙锁、next-key、死锁 | Lab 04：库存扣减死锁排查 |
| 日志与恢复 | redo、undo、binlog、崩溃恢复 | Lab 05：事务提交与崩溃恢复 |
| 复制与高可用 | GTID、异步复制、延迟、故障切换 | Lab 06：主从延迟与读写一致性 |
| 备份与恢复 | 逻辑备份、binlog、PITR、RPO/RTO | Lab 07：误删数据时间点恢复 |
| 运维与容量 | 慢日志、连接池、buffer pool、分页 | Lab 08：高负载数据库瓶颈排查 |

## 交付规范
每个实验包含问题背景、假设、架构或时序图、可运行代码、固定版本环境、自动化测试或故障脚本、实际日志、对照结果、局限与清理命令。压测和故障注入仅在隔离环境进行。按 `mysql/lab-XX-*/` 组织，完成后更新状态及成果链接；一个实验一个 PR。
