# JVM 工程实验路线

## 目标
以 Java 后端工程岗位为目标，通过可复现实验建立原理理解、设计、排障和优化能力。完成实验不等同于生产经验，不以背诵或实验数量直接认定精通。

## 技术基线
HotSpot JDK 17 基线；不同收集器或版本独立记录。遵循仓库 Maven 结构，具体版本在实现阶段固定。

## 能力清单

| 模块 | 核心知识 | 验证实验 |
|---|---|---|
| 运行时内存 | 堆、栈、元空间、直接内存 | Lab 01：四类内存故障诊断 |
| 字节码与执行 | Class 文件、操作数栈、invoke 指令 | Lab 02：从 Java 源码追踪字节码 |
| 类加载与初始化 | 加载、链接、初始化、双亲委派 | Lab 03：插件类加载隔离 |
| 垃圾收集 | 可达性、分代、G1、GC Roots | Lab 04：GC 压力与停顿对照 |
| 内存泄漏 | 堆转储、引用链、支配树 | Lab 05：定位缓存内存泄漏 |
| 线程诊断 | 线程转储、死锁、锁竞争、CPU | Lab 06：定位 CPU 飙升与线程死锁 |
| JIT 与基准 | 分层编译、内联、逃逸分析、预热 | Lab 07：JIT 优化与微基准陷阱 |
| 生产式调优 | JFR、jcmd、GC 日志、容器内存 | Lab 08：综合 JVM 性能故障演练 |

|---|---|---|---|
| 待做 | 01 | 四类内存故障诊断 | 分别构造堆 OOM、栈溢出、元空间与直接内存压力，限制进程资源；记录错误类型、参数及诊断证据，区分内存区域并安全清理 |
| 待做 | 02 | 从 Java 源码追踪字节码 | 使用 javap 分析多态、异常、lambda、synchronized 的字节码；逐例对应源码与指令，解释调用分派及异常表 |

| 待做 | 07 | JIT 优化与微基准陷阱 | 使用 JMH 对比预热、死代码消除、装箱和可观察的编译行为；记录 JVM 参数、fork、预热与误差，解释不可直接推断的优化 |
| 待做 | 08 | 综合 JVM 性能故障演练 | 构建有负载的服务，采集基线，逐项排查 CPU、分配和 GC；提供诊断时间线、瓶颈证据、单变量调优及回滚方案 |

## 交付规范
每个实验包含问题背景、假设、架构或时序图、可运行代码、固定版本环境、自动化测试或故障脚本、实际日志、对照结果、局限与清理命令。压测和故障注入仅在隔离环境进行。按 `jvm/lab-XX-*/` 组织，完成后更新状态及成果链接；一个实验一个 PR。

## 简历表达
完成相应实验后据实描述：熟练掌握 JVM 的核心机制，能够复现和分析典型工程问题，设计解决方案并通过测试或压测验证。没有真实生产经验时不声称生产调优或故障处理经历。
