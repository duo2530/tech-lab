# Elasticsearch 工程实验路线

## 目标
以 Java 后端工程岗位为目标，通过可复现实验建立原理理解、设计、排障和优化能力。完成实验不等同于生产经验，不以背诵或实验数量直接认定精通。

## 技术基线
固定 Elasticsearch 与 Java 客户端兼容版本，记录许可证相关限制。遵循仓库 Maven 结构，具体版本在实现阶段固定。

## 能力清单

| 模块 | 核心知识 | 验证实验 |
|---|---|---|
| 索引与映射 | Mapping、倒排索引、keyword/text、动态映射 | Lab 01：商品搜索索引建模 |
| 分词与相关性 | Analyzer、Tokenizer、BM25、boost | Lab 02：中文商品搜索相关性 |
| 查询与聚合 | bool、filter、range、聚合、排序 | Lab 03：商品筛选与销售分析 |
| 分页与搜索体验 | from/size、search_after、PIT、高亮 | Lab 04：深分页与稳定游标 |
| 写入与同步 | Bulk、refresh、版本控制、CDC | Lab 05：MySQL 到 ES 数据同步 |
| 分片与集群 | 主分片、副本、路由、分配、集群健康 | Lab 06：节点宕机与分片恢复 |
| 性能与容量 | Profile、慢日志、缓存、堆、批量写入 | Lab 07：搜索与写入性能调优 |
| 生命周期与恢复 | ILM、别名、reindex、快照 | Lab 08：索引迁移与备份恢复 |

| 待做 | 08 | 索引迁移与备份恢复 | 建立版本化索引和别名切换，执行 reindex、快照及测试恢复；校验迁移前后数据与查询，验证回滚和恢复时间，说明并发写入处理 |

## 交付规范
每个实验包含问题背景、假设、架构或时序图、可运行代码、固定版本环境、自动化测试或故障脚本、实际日志、对照结果、局限与清理命令。压测和故障注入仅在隔离环境进行。按 `elasticsearch/lab-XX-*/` 组织，完成后更新状态及成果链接；一个实验一个 PR。

## 简历表达
完成相应实验后据实描述：熟练掌握 Elasticsearch 的核心机制，能够复现和分析典型工程问题，设计解决方案并通过测试或压测验证。没有真实生产经验时不声称生产调优或故障处理经历。
